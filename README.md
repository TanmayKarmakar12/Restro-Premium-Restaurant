# 🍽️ Restro - Premium Restaurant Landing Page

A modern, high-performance, and visually appealing web application for high-end dining experiences. Built using **React**, **Tailwind CSS**, and **Lucide Icons**, this project showcases a polished restaurant brand landing page complete with step-by-step booking processes, dynamic testimonials, FAQ accordions, and fluid UI animations.

---

## ✨ Features

* **Hero Section**: Eye-catching call-to-actions, rating summaries, and high-resolution culinary visuals.
* **Signature Menu Showcase**: Interactive grid highlighting popular dishes, descriptions, and prices.
* **3-Step Booking Process**: Intuitive table reservation workflow broken down into simple steps.
* **Customer Testimonials**: Grid section displaying verified guest reviews and dynamic star ratings.
* **Interactive FAQs**: Animated collapsible accordion section utilizing HTML `<details>` and custom toggle icons.
* **Opening Hours Grid**: Styled schedule showcasing restaurant availability with conditional formatting for closed days.
* **Floating CTA Banner**: Dynamic call-to-action bar with floating dish imagery and hover effects.
* **Fully Responsive**: Optimized for seamless viewing across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

* **Frontend**: React (JSX)
* **Styling**: Tailwind CSS
* **Icons**: Lucide React
* **Animations**: Custom `Animated` wrapper components
